1. **Start the Server:**
   ```bash
   python simple_server.py
   ```
   Or double-click: `START_SERVER.bat`

2. **Open the Website:**
   - Open `index.html` in your browser
   - Click any service card with "Try Now" button
   - Fill in the form and get results!

## Server Status

The server will show which modules loaded successfully when you start it:
```
✓ Password Security loaded
✓ File Encryption loaded
...
Loaded 21 security modules
```

If a module fails to load, that specific feature won't work, but others will continue to function.

## Troubleshooting

**If a feature doesn't work:**
1. Check if the server is running
2. Check browser console for errors
3. Verify the module loaded in server startup messages
4. Make sure the `cybersecurity-solutions` folder exists at the correct path
